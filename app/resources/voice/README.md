# Voice cue samples
Short spoken words for section cues ("Verse two ... 2, 3, 4") and the spoken count-in.
Generated with Piper TTS (voice `en_US-lessac-medium`, length scale 0.8-0.85), trimmed, peak-normalised to -1 dBFS,
22.05 kHz mono 16-bit, by `tools/gen_voice.py`. Dataset license (Blizzard 2013 / Lessac) applies to the voice; it's fine for
personal use. Check https://www.cstr.ed.ac.uk/projects/blizzard/2013/lessac_blizzard2013/license.html before distributing the app.
Names not covered by these words are rendered on the iPad with AVSpeechSynthesizer (Platform_ios.mm).
